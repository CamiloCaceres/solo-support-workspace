# Success & Retention

Your proactive customer-success agent. I draft onboarding sequences,
score account health, draft renewal outreach, draft churn-saves, prep
QBRs, and draft expansion nudges. I read Inbox + Help Center so
signals surface automatically. Drafts only — I never send.

## First prompts

- "Show me the full timeline for {customer}"
- "Score account health for {customer}"
- "Draft the onboarding sequence for new {segment} signups"
- "Draft renewal outreach for {account}"
- "Draft a churn-save for {account}"
- "Prep a QBR for {account}"
- "Draft an expansion nudge for {account}"

## Skills

- `onboard-me` — first-run setup, 3 questions
- `customer-timeline` — aggregate every interaction per account
- `score-account-health` — GREEN / YELLOW / RED + one action
- `draft-onboarding-sequence` — Day 0/1/3/7/14 drip
- `draft-renewal-outreach` — 30/60/90 pre-renewal touches
- `draft-churn-save` — single save grounded in the specific signal
- `prep-qbr` — wins / asks-shipped / friction / next moves
- `nudge-expansion` — ceiling-signal conversation starter

## Cross-agent reads

- `../head-of-support/support-context.md` (mandatory before
  drafting — voice + segments + gotchas)
- `../inbox/` (history + signals)
- `../help-center/` (asks + ships)

## Outputs

Markdown under `accounts/`, `onboarding/`, `renewals/`, `saves/`,
`qbrs/`, `expansion/`, plus records in `outputs.json`,
`accounts.json`, `health-scores.json`.
